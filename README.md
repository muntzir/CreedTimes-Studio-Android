# CreedTimes Studio Mobile

Android version of CreedTimes editorial post generator.

## Features
- Creed Times dark navy + burnt orange mobile UI
- Image picker, drag/drop where WebView supports it, clipboard image paste, Android share-to-app
- Direct image URL + article URL / OG image fetch
- CSV + XLSX bulk headline import with category and image_url columns
- Full headline highlight, Urdu/English, Nastaliq word-gap control
- Blur region, gradient, Breaking News badge positioning, logo library, footer URL controls
- Film grain, dots, halftone, newspaper, scan lines, CRT, VHS, grid, dust overlays
- HD PNG export (1x / 2x / 3x), Android Gallery/Downloads saving
- Bulk ZIP export and Android share sheet
- Local presets

Package: `com.creedtimes.studio`
Minimum Android: 9 / API 28
