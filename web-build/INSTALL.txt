CREED TIMES 2.0 — INSTALLATION

IMPORTANT:
- You already have a full Hostinger backup. Keep it.
- Do not delete old content, media, authors or URLs.
- Install the Core plugin first, then the Theme.
- The migration included here is intentionally non-destructive.

1) INSTALL THE CORE PLUGIN
WordPress > Plugins > Add New Plugin > Upload Plugin
Upload: creed-times-core-2.0.zip
Activate it.

2) RUN SAFE CONTENT MIGRATION
WordPress > Creed Times
Click: Run Safe Creed Times Migration

This will:
- keep existing posts, authors, media, dates, slugs and URLs
- create new editorial taxonomies: Language, Editorial Format, Region, Topic
- map Urdu / Roman Urdu safely
- map West Asia / World into Regions
- map Analysis / News / Documentaries into Editorial Formats
- map Politics / Religion / Art into Topics
- map legacy “For Subscribers” content to Creed Pro
- mark obvious old Glossier/demo tags as legacy so the new theme hides them
- NOT delete old categories/tags/content

3) INSTALL THE THEME
WordPress > Appearance > Themes > Add New Theme > Upload Theme
Upload: creed-times-2.0-theme.zip
Activate it.

4) SET OFFICIAL LOGO + FAVICON
Appearance > Customize > Site Identity:
- Custom Logo: upload/select your official Creed Times blue/orange full logo
- Site Icon: upload/select your official Creed Times monogram/favicon

The theme intentionally uses WordPress Custom Logo and Site Icon so your real supplied brand files are used instead of a recreated logo.

5) NAVIGATION
Appearance > Menus:
Assign your main menu to “Primary Navigation”.

7) CREED PRO
The plugin integrates with Paid Memberships Pro if it is active.
WordPress > Creed Times:
Enter the PMPro Membership Level ID(s) that should unlock Creed Pro.
If left blank, any active PMPro membership is treated as Pro.
